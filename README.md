# 融智云考题库导出桌面系统 (YunKao Desktop)

基于 PySide6 + QWebEngine 构建的融智云考练习题提取与导出工具。通过内嵌 Chromium 浏览器引擎，无缝接入沈理校园（SYLUlive）用户体系，实现自动化的题库爬取与一键导出。

## 🌟 核心特性

- **沈理校园账号打通**：使用 `SYLUlive` 体系的学号和密码登录，并支持基于后端的 VIP 权益校验。
- **本地硬件级安全存储**：您的融智云考密码不会上传到任何服务器！本软件使用系统原生的凭据管理器（Windows Credential Locker / macOS Keychain）进行高强度加密本地存储。
- **一键免密填充**：启动进入练习页面后，自动读取本地加密的云考密码并注入网页，实现免密登录。
- **自动化循环提取**：包含**“自动进入下一题”**功能，彻底解放双手，自动模拟点击翻页并持续抓取题库。
- **多格式离线导出**：提取完成后，支持一键将题库导出为清晰美观排版的 **Markdown (`.md`)** 或 **纯文本 (`.txt`)** 文件。

---

## 🛠️ 环境准备与安装

1. **Python 环境**：需要 Python 3.8+ (推荐 Python 3.11)。
2. **安装依赖**：
   在项目根目录下打开终端（或使用当前已经建好的 `venv` 虚拟环境），运行：
   ```bash
   pip install -r requirements.txt
   ```
   *(如果还没有 requirements.txt，请手动安装: `pip install PySide6 requests bs4 keyring`)*

## 🚀 使用指南

### 1. 启动软件
执行以下命令启动应用：
```bash
python main.py
```
或使用虚拟环境：
```bash
.\venv\Scripts\python.exe main.py
```

### 2. 账号登录
- **学号/密码**：输入您在沈理校园 App / SYLUlive 的账号和密码。
- **云考独立密码**：如果您的云考密码和系统密码不一致，请在下方单独填入。勾选“记住密码”后，该密码将仅保存在您电脑本机的安全芯片内。
- **提示**：如果点击登录时界面**“卡住”**，是因为软件正在连接服务器 (`101.42.27.44`) 验证身份。若网络不通畅，最长可能会等待 10 秒钟（超时），请耐心等待。

### 3. 开始提取题库
1. 成功登录后，右侧浏览器会自动加载“融智云考”登录页。
2. 软件会自动为您填入云考账号密码，点击登录进入您的练习题库页面。
3. **手动提取**：进入具体某一道练习题后，点击左侧的 **“🚀 提取当前题目”**。
4. **全自动连续提取**：
   - 勾选 **“自动进入下一题 (循环提取)”** 复选框。
   - 再次点击 **“🚀 提取当前题目”**。
   - 此时可以把双手离开键盘，软件会自动提取、翻页、再提取，直到本章节所有题目提取完毕。

### 4. 导出文件
提取到您需要的题量后，点击左侧的 **“💾 导出基础题库 (免费)”** 按钮。
- 在弹出的保存窗口中，选择保存路径。
- **格式选择**：在底部“保存类型”下拉菜单中，您可以选择保存为 **Markdown (.md)** 或 **普通文本 (.txt)**。
- 导出成功后即可使用外部编辑器（如 Typora, VSCode 或记事本）打开查看完美排版的题目和选项。

## 🔒 隐私与安全声明

- **零云端记录**：本客户端仅请求 `/api/login` 获取 JWT 令牌及 VIP 状态，**不会**将您的融智云考密码发送给后端服务器。
- **VIP 权益**：软件左下角会实时显示您的沈理校园 VIP 状态。高级 AI 美化排版等增值功能将仅面向 VIP 用户开放（开发中）。
