# 融智云考题库导出桌面软件 · 完整实施计划（接入 SYLUlive 体系）

> **版本**：v1.0（基于 SYLUlive 后端生态）  
> **技术栈**：Python 3.11 + PySide6 + QWebEngine + SYLUlive Go 后端 API  
> **核心原则**：云端绝不存储任何第三方学校账号密码；所有敏感信息仅留存于用户本地加密存储中；接入现有沈理校园用户体系，实现统一鉴权与 VIP 变现。

---

## 一、产品定位与商业模型

- **产品形态**：Windows/macOS 桌面应用，内嵌 Chromium 浏览器，直接操作融智云考页面。
- **商业模式**：
  - **免费功能**：基础题目抓取与导出（TXT/Markdown 纯净版）。
  - **付费高级功能**：AI 智能排版、自动生成解析、水印添加、离线图片/公式完整导出。
- **收费方式**：对接 SYLUlive 现有后端 VIP 体系，复用现有用户数据库，由超级管理员在后台控制台充值发放 VIP 时长。

## 三、核心模块详细设计（重点：与 SYLUlive 集成）

### 1. 商业化鉴权与安全模块（对接 SYLUlive 后端）

#### 1.1 复用现有 SYLUlive 后端体系
您的沈理校园项目已有一套成熟的 Go 后端（`server/`），使用 Gin 框架、GORM、JWT 鉴权。融智云考桌面软件的用户体系应完全复用该后端，避免新建独立的用户系统。

**现有后端关键信息**：
- 用户模型通常在 `internal/models/` 中定义（如 `user.go`），包含 `Username`, `Password`, `StudentId`, `Token` 等字段。
- 登录逻辑在 `internal/handlers/auth.go`，现有接口 `POST /api/login` 已返回 JWT Token。
- 已有完善的分布式管理员、超级管理员体系，可方便地管理 VIP 充值。

#### 1.2 后端改造计划（新增 VIP 支持）
**目标**：在现有用户表中增加 VIP 过期时间字段，并提供 VIP 状态校验接口。

- **修改 `internal/models/user.go`**：在 `User` 结构体中添加字段：
  ```go
  VipExpiry *time.Time `json:"vip_expiry" gorm:"index"`
  ```
- **数据库迁移**：执行 `AutoMigrate` 或手动增加列 `vip_expiry`。
- **登录接口增强**：修改 `POST /api/login`，在返回的 JWT payload 中加入 `vip_expiry` 字段，客户端可直接从 Token 解析 VIP 状态。
- **新增 VIP 校验接口**：`POST /api/check-vip`，客户端发送 JWT，服务端判断 `VipExpiry > time.Now()`，返回 `{"is_vip": true, "expiry": "..."}`。此接口独立于登录，可用于按钮点击时的实时校验。
- **超级管理员面板扩展**：在现有超级管理员界面中增加 VIP 充值/延期功能，可填入用户 ID 或学号，设置/延长 VIP 有效期。

#### 1.3 客户端鉴权流程（对接 SYLUlive）
1. **软件启动** → 显示登录界面，要求输入 **沈理校园** 的账号密码（即 SYLUlive 账户）。
2. 调用 `POST /api/login`（baseUrl 指向您的后端服务器），获取 JWT Token，解析出 `vip_expiry` 并保存在内存中。
3. **免费功能**：基础提取（简单 Markdown）无需校验 VIP，登录后即可使用。
4. **高级功能拦截**：当用户点击“AI高级导出”等 VIP 功能时，客户端发送 JWT 到 `/api/check-vip` 进行二次确认。若为非 VIP，弹窗引导：“该功能为高级会员专属，请前往沈理校园 App 或网页端升级 VIP”。同时可在客户端显示“购买VIP”跳转链接。
5. **Token 刷新**：若 JWT 支持刷新，客户端应在 Token 即将过期时调用刷新接口，保持会话活跃。

#### 1.4 本地第三方密码安全存储（核心红线）
- **禁止**：将融智云考的校园编码、账号、密码上传至 SYLUlive 服务器或任何云端。
- **存储方式**：
  - 使用 `keyring` 库（封装 Windows DPAPI、macOS Keychain、Linux Secret Service），使用操作系统当前用户凭据加密存储。
  - 存储内容为 JSON 字符串：`{"school_code":"...", "student_id":"...", "password":"..."}`，整体加密。
- **Cookie 持久化**：融智云考登录后的 Session Cookie 同样加密存储在本地，下次启动时自动恢复，避免重复半自动登录。

完全保留原设计：极简 JS 提取 → Python 清洗规则引擎 → 动态 `rules.json` 配置。该模块与后端体系无关，保持独立。

### 4. 资源离线化与公式完美保留

同上，图片异步下载、公式 LaTeX/SVG 提取。

---

### 5. AI 智能层与异步工程化

- AI 调用通过 **SYLUlive 后端代理**，不在客户端直接调用外部大模型 API，便于权限控制、成本管理和内容审核。
- 后端新增 AI 代理接口（或在现有 Python 教务服务中扩展），接收 JWT + 题目内容，转发至大模型并返回结果（支持流式）。
- 客户端使用 `QThread` + 信号槽处理流式响应，保持 UI 流畅。

## 六、风险对策与长期维护

| 风险项 | 应对方案 |
|--------|----------|
| SYLUlive 后端 API 变动 | 桌面端配置化 baseUrl 和接口路径，后端遵循版本化 API（如 `/v1/`） |
| VIP 字段被用户篡改（客户端） | 所有 VIP 校验必须经由服务端接口，客户端不可信任本地判断 |
| 用户密码在客户端内存中泄露 | 使用 keyring 仅按需解密，使用后立即清除变量；登录后密码不保存于内存 |
| AI 调用成本过高 | 后端代理设置每用户每日额度，支持流式传输以优化体验 |
