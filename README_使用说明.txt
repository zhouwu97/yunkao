             融智云考导出系统 - 使用说明与运行环境
=============================================================
作者项目主页: https://github.com/zhouwu97

【运行环境要求】
1. 本软件为纯绿色、免安装独立运行版本。
2. 只要是 64位的 Windows 10 或 Windows 11 普通电脑，双击“yunkao.exe”即可直接运行！
3. 您【不需要】额外安装任何 Python 环境，也【不需要】安装 Chrome 浏览器，所有底层依赖（包括极速 PDF 渲染引擎）均已内置在软件内部！

【防呆提示与常见问题排查】
🔴 1. 软件打不开 / 弹窗报错？
由于本软件采用了底层进程隐藏和防篡改技术，部分杀毒软件（如 360安全卫士、火绒等）可能会产生误报或拦截。
【解决方法】：如果在运行中出现闪退或报错，请尝试将“yunkao.exe”添加至杀毒软件的信任区，或暂时退出杀毒软件后再次运行。

🔴 2. 导出 PDF 失败，或图片全是 [图片加载失败]？
【解决方法】：本系统默认使用内置的“Chromium极速内核”，不需要额外软件。
但是，如果您在软件设置中【强制切换为了经典 WPS 内核】，那么您的电脑【必须】提前安装好了“WPS Office”或“Microsoft Office (Word)”。如果没有安装，系统将会直接报错并导致 PDF 导出崩溃。
如果您的电脑是一台什么都没装的新电脑，请务必在设置中保持使用“极速 Chromium 内核（推荐）”！

🔴 3. 为什么导出总是提示“沈理校园账号密码错误”或“云考密码错误”？
【解决方法】：
- 您登录时需要输入的账号密码与您在“沈理校园”APP 中完全一致！
- “云考密码”默认自动填充为“123456”。如果不确定，建议您保持默认 123456 不动。如果您修改过密码，可以点击右侧的“👁”小眼睛图标，仔细核对输入是否正确（注意大小写和空格）。

🔴 4. 提取到一半突然卡住不动了？
【解决方法】：网络波动可能导致图片或题库加载超时。您可以点击“⏹ 停止提取”，然后点击“🗑️ 清空”，刷新网页后再次尝试。请确保网络环境畅通！
