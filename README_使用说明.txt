融智云考桌面版 v2.0.0

1. 安装 WebView2 Evergreen Runtime。
2. 启动 YunKao.App.exe，进入设置填写云考账号；密码只保存到本机系统凭据库。
3. 在工作台打开练习页面，点击“开始提取”。页面加载、登录失效或下一题异常时，任务会暂停并保留已经保存的题目。
4. 点击“停止”只停止继续抓题，不会删除已有题目；已有题目可以立即导出 PDF、DOCX、Markdown 或 TXT。
5. 工作台切换到设置、历史、导出或诊断后，返回工作台会保留页面、地址、题目和进度。

说明：桌面版不包含钱包、充值、官方代理、管理后台或 admin API。正式包由 build_unified_bundle.ps1 生成，版本号来自根目录 VERSION。
