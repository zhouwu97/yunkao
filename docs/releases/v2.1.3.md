# 融智云考桌面版 v2.1.3

修复设置页开关连续操作时的动画中断，液态玻璃材质沿用 v2.1.2。

- 连续轻点时保留当前位置与速度，直接转向新目标，不重复等待鼓起。
- 动画中再次按下保持原行程，确认拖动后从当前画面接管。
- 拖出轨道后反向移动立即跟随，消除越界位移形成的死区。
- 持续按住时保持展开；取消恢复已提交状态，松手只提交一次设置。

下载 Windows x64 压缩包，完整解压到新目录，运行 `YunKao.App.exe`。升级前关闭旧窗口；本地设置、凭据与题库历史继续使用原来的用户数据目录。

发布包自带 .NET 运行库和 Python Worker，无需另装 Python。内置网页需要 WebView2 Runtime，PDF 导出需要本机可用的 Word 或 WPS。

验证范围：开关运动回归、项目测试、Python 与网页桥接测试，以及发布包完整性和 Worker 导出冒烟。不同 GPU、跨显示器 DPI 和硬件帧率未覆盖。
