# 融智云考桌面版 v2.1.0

任务卡、诊断面板和相关按钮新增透明液态玻璃。按住空白处拉扯时，抓取处的边缘、折射和高光一起形变，松手弹性回落；卡片主体与文字保持固定。减少动画、高对比度和关闭系统透明效果时提供对应回退。

本版还包括：

- 导航使用独立玻璃选中透镜，去除白色选择底条。
- 优化最大化、普通和窄窗口的侧栏人物布局，人物贴近任务卡，原图底部由卡片自然遮挡。
- 历史记录可搜索课程或题库链接，导出记录可搜索文件或格式；改进同一时间多条记录的分页和搜索响应。
- 改善地址栏、网页加载失败后的恢复提示和任务开始时的重复点击处理。
- 保留原生按钮点击、文本编辑与选择、滚动和键盘操作。

下载 Windows x64 压缩包，完整解压到新目录，运行 `YunKao.App.exe`。升级前关闭旧窗口，保留整个发布目录；本地设置、凭据与题库历史继续使用原来的用户数据目录。

发布包自带 .NET 运行库和 Python Worker，无需另装 Python。内置网页仍需要 WebView2 Runtime，PDF 导出仍需要本机可用的 Word 或 WPS。

验证：189 项 C#、37 项 Python 和 5 项网页桥接测试通过；冻结 Worker 完成 6 类题目解析、6 次答案版/练习版导出及图片失败恢复检查。Windows x64 压缩包已重新解压并验证版本、资源、GPU 材质和页面导航。
