# 融智云考桌面版 v2.1.1

更新软件图标，并完善液态玻璃面板和设置开关的交互。

- EXE、窗口、任务栏及应用包使用统一的新图标，包含 Windows 各个显示尺寸。
- 设置开关按住后放大为玻璃透镜，折射轨道和周围背景；拖动越过中点后切换轨道颜色，松手才保存状态，取消则恢复。
- 改善任务卡、设置及诊断大面板的清透效果，修复滚动超出背景捕获范围时出现的黑条。
- 完善诊断面板空白区域的拖动响应，保留文本编辑、选择、子控件、键盘和辅助功能操作。

下载 Windows x64 压缩包，完整解压到新目录，运行 `YunKao.App.exe`。升级前关闭旧窗口；本地设置、凭据与题库历史继续使用原来的用户数据目录。

发布包自带 .NET 运行库和 Python Worker，无需另装 Python。内置网页需要 WebView2 Runtime，PDF 导出需要本机可用的 Word 或 WPS。
